# Инициализация базы данных

Файлы `.sql`, `.sql.gz` и `.sh` из этого каталога выполняются **только при первом
создании** тома с данными MariaDB — в алфавитном порядке имён.

Положите сюда схему проекта, например `01-schema.sql`, `02-seed.sql`.

Если том уже создан, скрипты отсюда повторно не запустятся. Чтобы применить их
заново, придётся удалить том вместе с данными:

```bash
make clean          # docker compose down -v — удалит данные БД
make up
```

Готовый дамп с данными удобнее заливать отдельно, не трогая том:

```bash
make db-import FILE=dump.sql
```
